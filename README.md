# Smart Greenhouse Monitoring & Data Analytics

A data-driven smart agriculture project that combines **IoT, MySQL, and Power BI** to transform greenhouse and soil sensor data into actionable insights for better agricultural decision-making.

---

## Project Objective

Monitor and analyze key environmental conditions such as **soil moisture, temperature, pH, and humidity** to identify unfavorable conditions, optimize irrigation, and improve resource utilization.

---

## Data Workflow

**IoT Sensors → MySQL → Power Query → Power BI → DAX & KPIs → Interactive Dashboards → Insights & Recommendations**

---

## Dashboards

### 1. Daily Sensors Summary
Provides a high-level view of the greenhouse conditions, including:

- Crop Health Score
- Temperature
- Soil Moisture
- pH Level
- Weather Temperature
- Weather Humidity
- Recommendations & Alerts

### 2. Daily Sensor Insights
Provides deeper analysis through:

- Environmental Quality Score
- Time-based sensor readings
- Heatmaps
- Temperature trends
- Historical pattern analysis

### 3. Weather Analysis
Analyzes environmental conditions over time, including:

- Temperature patterns
- Humidity trends
- Daily variations

### 4. Sensor Readings Analysis
Analyzes sensor readings across different time intervals to identify:

- Trends
- Patterns
- Sudden changes
- Potential anomalies

## Key Outcomes

The project transforms raw sensor readings into:

- Interactive visual insights
- KPIs and performance indicators
- Alerts and recommendations
- Data-driven irrigation decisions
- Resource optimization insights

Simulation results indicated a potential **20–30% reduction in water consumption** through data-driven monitoring and irrigation optimization.
